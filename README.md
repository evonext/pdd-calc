# Калькулятор Pinduoduo → Казахстан

Показывает, что дешевле: прямая доставка через Казпочту или карго, и как лучше платить — картой, Alipay, WeChat или с баланса Alipay.

## Как запустить
1. Загрузите все файлы в репозиторий, вместе с папками `.github` и `scripts`.
2. Settings → Pages → Source: «Deploy from a branch», ветка `main`, папка `/ (root)`.
3. Actions → «Обновить курсы» → Run workflow (первый запуск вручную, чтобы проверить).

## Что обновляется само
- `rates.json` — курс НБРК (¥, $, €). GitHub Action обновляет его каждый день в 17:40 и 06:10 по Алматы.
  Если сайт Нацбанка недоступен, подставляется рыночный курс (видно в строке курса).
- Если `rates.json` старше 4 дней, страница сама подтянет рыночный курс.

## Что нужно править руками (`config.json`)
Комиссии, НДС, наценка Kaspi к курсу НБРК (по умолчанию 1%), тарифы карго, лимиты таможни.
Курса Kaspi нет в открытом доступе — точный курс можно вписать в «Тонких настройках».
